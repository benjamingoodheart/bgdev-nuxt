# benjamin.goodheart.dev

This is the open source code for my personal developent website. It is built on Nuxt 4 and Vue 3. To install and run in development mode: 

```bash
clone https://github.com/benjamingoodheart/bgdev-nuxt.git
cd bgdev-nuxt
npm i 
npm run dev
```

To build
```bash
npm run build
node .output/server/index.mjs
```
